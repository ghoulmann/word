# Authorization Response (MTI 0110)

Returned by an issuer in response to an authorization request (MTI 0100). Contains the authorization decision and, if approved, an authorization code.

The authorization response carries [[field-039|Response Code]] as
the primary decision indicator. A value of `00` indicates approval;
values such as `05` (Do Not Honor), `51` (Insufficient Funds), and
`14` (Invalid Card Number) indicate decline with reason.

If approved, [[field-038|Authorization ID Response]] carries the
six-character authorization code that must be stored and referenced
in subsequent clearing and settlement messages.

## Response code categories

| Range | Meaning |
|---|---|
| 00 | Approved |
| 01–09 | Refer to issuer |
| 10–19 | Invalid transaction |
| 51–59 | Insufficient funds / limits |
| 91–96 | System unavailability |
