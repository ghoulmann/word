# Network Management Response (MTI 0810)

The response to a Network Management Request ([[mti-0800]]). Field 039 (Response Code) indicates success or failure of the requested operation. Field 070 (Network Management Information Code) echoes the function code from the request.

MTI 0810 is used at session level — not tied to cardholder transactions. A successful sign-on (code 001) exchange enables subsequent authorization and financial message flows.
