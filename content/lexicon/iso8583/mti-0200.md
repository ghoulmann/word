# Financial Transaction Request (MTI 0200)

A request that both authorizes and records a financial transaction in a single message. Used when authorization and capture occur simultaneously, as in most debit and ATM transactions.

Unlike a two-step authorize-then-capture flow, a financial transaction request combines both steps. The
issuer both authorizes and posts the transaction in a single
exchange. Common in debit, ATM withdrawals, and some online
payment flows.

[[field-037|Retrieval Reference Number]] must be unique per
transaction and is used for dispute resolution and reconciliation.
