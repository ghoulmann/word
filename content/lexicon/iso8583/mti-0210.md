# Financial Transaction Response (MTI 0210)

Returned by an issuer in response to a financial transaction request (MTI 0200).

Carries the same decision fields as [[mti-0110]] — [[field-039]]
for the response code and [[field-038]] for the authorization code
on approval. Because the financial transaction request posts
immediately, a decline response must be treated as final with no
retry without customer interaction.
