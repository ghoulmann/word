# ICC Data (Field 055)

Data elements exchanged between the terminal and the chip card during an EMV transaction. Contains cryptograms, terminal verification results, and other chip-generated data.

ICC Data carries TLV (Tag-Length-Value) encoded EMV data
elements including:

- **Application Cryptogram (AC)**: ARQC (authorization request
  cryptogram) generated by the chip, validated by the issuer
- **Terminal Verification Results (TVR)**: flags indicating
  checks performed by the terminal
- **Application Interchange Profile (AIP)**: card capabilities
- **Cryptogram Information Data (CID)**: cryptogram type indicator

The issuer validates the ARQC online and returns an ARPC
(authorization response cryptogram) in the response. This
mutual authentication is the primary anti-counterfeiting
mechanism of EMV.

Presence of Field 055 with a valid ARQC generally shifts
counterfeit fraud liability to the issuer. Absence of Field
055 at a chip-capable terminal shifts liability to the acquirer.
