# Reversal Request (MTI 0400)

Sent by an acquirer to cancel a previously authorized or completed financial transaction, typically due to a terminal timeout, communication failure, or customer cancellation.

A reversal is initiated by the acquirer, not the cardholder. It is
used to undo a transaction the terminal believes it sent but did not
receive confirmation for (timeout reversal), or to cancel a
transaction the merchant initiates (void).

Field 090 (Original Data Elements) carries the original data elements from the message
being reversed, allowing the issuer to match and cancel the
original authorization or financial transaction.

Reversals differ from refunds: a reversal cancels before settlement;
a refund (MTI 0200 with processing code `20`) is a separate credit
transaction after settlement.
