# Network Management Request (MTI 0800)

Used for network-level operations: sign-on, sign-off, echo test, and key exchange. Not a cardholder transaction.

Network management messages maintain the communication link between
acquirer and issuer processors. [[field-070|Network Management
Information Code]] determines the operation:

| Code | Operation |
|---|---|
| 001 | Sign-on |
| 002 | Sign-off |
| 301 | Echo test |
| 101 | Master key download |

Sign-on (0800/001) is sent at session start and must be acknowledged
before cardholder transactions are processed. Echo tests (0800/301)
verify link availability and measure latency.
