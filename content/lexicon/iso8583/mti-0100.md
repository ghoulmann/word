# Authorization Request (MTI 0100)

Sent by an acquirer to an issuer to request authorization for a payment card transaction before funds are committed. The issuer responds with MTI 0110.

An authorization request does not move funds — it asks the issuer
whether the cardholder has sufficient credit or funds and whether
the card is valid. The issuer returns [[mti-0110]] with
[[field-039|Response Code]] indicating approval or decline.

Authorization requests are used for card-present and card-not-present
purchases, cash advances, and pre-authorizations (hotel holds, car
rentals). The transaction amount in [[field-004]] may differ from the
final settlement amount in card-not-present scenarios.

## Key data elements

- [[field-002]] — Primary Account Number identifies the cardholder account
- [[field-003]] — Processing Code defines the transaction type
- [[field-004]] — Transaction Amount in minor units
- [[field-022]] — Point of Service Entry Mode (chip, swipe, contactless, manual)
- [[field-055]] — ICC Data carries EMV chip data for chip transactions
