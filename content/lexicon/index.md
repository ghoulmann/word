# Lexicon

Structured terminology across multiple domains. Each taxonomy uses consistent classification dimensions, typed relationships, and diagnostic guidance. Concepts link across taxonomies where domains intersect.

## Taxonomies

### [[wqo/index|Writing Quality Ontology (WQO)]]
Concepts describing how text fails or succeeds — intrinsic properties of written content across functional, computational, mechanical, structural, and editorial layers.

### [[iso8583/index|ISO 8583 — Financial Transaction Messages]]
Fields, message types, and data elements defined by ISO 8583, the international standard for financial transaction card-originated messages.
