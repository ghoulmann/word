# Framework

Four pages explain the logic behind the ontology. Read them in order if you are new to the system; return to them when a classification decision is unclear.

- **[[five-layers]]** — The five editorial layers, their names, what each governs, and why the ordering is not arbitrary.
- **[[triage-sequencing]]** — The triage principle: why you should not fix commas before structure is stable, how `address_when` encodes that principle, and how `prerequisite_for` represents it as a graph edge.
- **[[category-boundaries]]** — When a concern in one layer becomes a concern in another. Cascade thresholds, category errors, the pre-compositional split, and concepts that are orthogonal axes rather than nested items.
- **[[relationship-types]]** — The open set of typed edges connecting concepts. What each type means, how `impediment_to` differs from `increases_risk_of`, and how to choose when both seem to apply.
